Agentic AI for playing Rayman Legends

June 2026 - Ongoing

This project is focused on developing an agentic AI system for playing Rayman Legends. The goal is to create an intelligent agent that can navigate the game environment and pass all levels.

This work is currenly in progress. An update will follow after its completion, which is expected to be around the end of 2027. Currently this is the second most complex project I have ever undertaken in terms of an AI project, after the aircraft decrabbing project.
